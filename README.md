# Projeto de Desenvolvimento de Sistemas - PHP

Todo o sistema está na pasta **[`sistema-escolar/`](sistema-escolar/)**. As instruções de instalação, os usuários de teste e as formas de acessar o banco de dados estão no [README do sistema](sistema-escolar/README.md).

**Módulos:** agenda de tarefas do aluno com login • reserva de salas e laboratório de informática • cantina escolar com pedidos e relatórios • help desk de TI (chamados).

**Tecnologias:** HTML, CSS, JavaScript (fetch/JSON) • PHP 8 (PDO) • MySQL/MariaDB
